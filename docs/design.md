# ONIE v0.1 — Visual Design

ONIE is voice-first, not chat-first.

## Visual identity

- Dark sci-fi background
- Cyan/blue core as ONIE's primary identity
- Violet for processing/thinking
- Green for successful execution
- Minimal text
- Voice waveform for listening/speaking
- Core animation represents ONIE's current state

## States

IDLE → WAKE → LISTENING → THINKING → SPEAKING → IDLE

Sensitive actions will later add:

CONFIRMING → AUTHENTICATING → EXECUTING → SPEAKING

## Product principle

The UI communicates ONIE's state; the voice interaction remains primary.
